# 152-ФЗ и Foreign Providers

## Overview

Фреймворк `regulated-llm-eval` спроектирован для использования в regulated-доменах РФ (налоги, бухгалтерия, право). Персональные данные (ПИД) обрабатываются в соответствии с Федеральным законом №152-ФЗ «О персональных данных».

## Provider Allowlist

### По умолчанию

Разрешены **только российские провайдеры**:

| Провайдер | Статус | Соответствует 152-ФЗ |
|-----------|--------|----------------------|
| **YandexGPT** | ✅ Allowed | Да (данные в РФ) |
| **GigaChat** | ✅ Allowed | Да (данные в РФ) |
| **OpenAI-compatible** | ❌ Blocked | Нет (данные за пределами РФ) |

### Opt-in для foreign providers

Для OpenAI-compatible требуется **двойной opt-in**:

#### CLI

```bash
regulated-eval run \
  --dataset tax_qa_v1@0.1.0 \
  --model openai_compat \
  --allow-foreign-provider \
  --i-understand-152fz
```

Оба флага обязательны. Без них — `ForeignProviderNotAllowed` (exit code 4).

#### Environment variables (для CI)

```bash
export REGULATED_EVAL_ALLOW_FOREIGN_PROVIDER=true
export REGULATED_EVAL_ACK_152FZ=true
```

> ⚠️ При использовании env-переменных в stderr выводится предупреждение.

### Audit-лог

Каждое разрешение foreign provider фиксируется:

```json
{
  "event": "provider.foreign.allowed",
  "provider": "openai",
  "ack.source": "cli",
  "trace_id": "abc-123"
}
```

## PII Redaction

### Что редактируется

| Тип PII | Пример | Regex / Presidio |
|---------|--------|------------------|
| ФИО | Иванов Иван Иванович | Presidio + regex |
| ИНН | 7707083893 | Regex (10/12 цифр) |
| СНИЛС | 123-456-789 01 | Regex |
| Паспорт | 45 12 123456 | Regex |
| Телефон | +7 (999) 123-45-67 | Regex |
| Email | user@example.com | Regex |
| Адрес | ул. Тверская, д. 1 | Regex |

### Redaction policy

1. **До отправки в LLM** — все PII-поля редактируются в `PIIRedactor`.
2. **Audit-лог** — только `field.name`, без значений.
3. **OTel-атрибуты** — `RedactingSpanProcessor` дропает не-allowlist атрибуты.

### Пример

**Input:**
```
Вопрос: ИНН 7707083893, сколько платить УСН 6% с оборота 10 млн?
```

**Redacted:**
```
Вопрос: [INN], сколько платить УСН 6% с оборота 10 млн?
```

**Audit-log:**
```json
{
  "event": "security.pii.redacted",
  "field.name": "INN",
  "run.id": "abc-123",
  "pii_redacted": true
}
```

## Threat Model

### TM-02: PII утечка в LLM

- **Risk:** 16 (Critical)
- **Mitigation:** PII-redaction до отправки в LLM, audit-log, OTel redaction
- **Test:** TC-SEC-002 (recall ≥ 99%)

### TM-06: Data residency

- **Risk:** 12 (High)
- **Mitigation:** Provider allowlist, opt-in для foreign providers
- **Test:** TC-SEC-001

### TM-08: Secrets в логах

- **Risk:** 12 (High)
- **Mitigation:** API keys не логируются, OTel redaction
- **Test:** TC-SEC-004

## Compliance Checklist

- [x] PII-redaction до отправки в LLM
- [x] Audit-log только с field.name (без значений)
- [x] Provider allowlist (только РФ по умолчанию)
- [x] Double opt-in для foreign providers
- [x] OTel redaction (RedactingSpanProcessor)
- [x] API keys не логируются
- [ ] DPA с провайдером (ответственность заказчика)
- [ ] Регистрация базы ПИД в Роскомнадзоре (ответственность заказчика)

> **Примечание:** фреймворк обеспечивает технические средства compliance. Юридическая ответственность за обработку ПИД лежит на заказчике.
