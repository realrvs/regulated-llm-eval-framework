# Синхронизация статуса Issue

После завершения работы над задачей (ID вида T-xxx), когда код написан и проверен, необходимо:
1. Найти номер соответствующего Issue на GitHub с помощью команды в терминале: 
   `gh issue list --search "T-xxx" --json number -q ".[0].number"`
2. Закрыть найденный Issue командой:
   `gh issue close <номер> --comment "Реализовано в рамках задачи"`
3. Если Issue не найден, сообщить об этом пользователю.
